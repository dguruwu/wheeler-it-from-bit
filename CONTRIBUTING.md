# Contributing — the narrow path
1. Price every claim: [RECEIPT] / [RECALLED] / [EXTENSION] / [NULL]. Name the probe for receipts.
2. Append, never erase. Corrections wrap the original in BEFORE/AFTER blocks.
3. Verify on revisit: fitness-bearing renderings are welcome, and must be revisited for
   veridical homomorphicality (structure-preserving mapping to the primary sources).
4. Quote the primary source, not paraphrases of it.
5. Hallucinated or confabulated entries are not purged — they are carried, priced, and
   revisited. The record is append-only.
